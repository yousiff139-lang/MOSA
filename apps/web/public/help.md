# دليل المستخدم - MOSA Smart Home

## تسجيل الدخول
- اسم المستخدم: admin
- الرمز السري: 1234
- غيّر الرمز من الإعدادات فور الدخول

## إضافة جهاز جديد
1. اذهب إلى "الأجهزة"
2. اضغط "إضافة جهاز"
3. أدخل اسم الجهاز والغرفة
4. امسح QR code أو أدخل MAC address

## إنشاء سيناريو
1. اذهب إلى "المشاهد"
2. اضغط "سيناريو جديد"
3. اختر الأجهزة والحالات المطلوبة
4. احفظ واضغط تشغيل

## استكشاف الأخطاء
- إذا لم يستجب الجهاز: تحقق من الاتصال بالشبكة
- إذا ظهر "مقطوع": أعد تشغيل ESP32
