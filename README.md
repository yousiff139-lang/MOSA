# MosaSmartNode Platform 🚀

نظام منزل ذكي متكامل مبني من الصفر، مصمم للعمل محلياً بالكامل (Local-First) للحفاظ على الخصوصية والسرعة، مع إمكانية التحكم السحابي الآمن.

## الفكرة الأساسية
بدلاً من الاعتماد على أجهزة تجارية (مثل Tuya أو Sonoff) التي ترسل بياناتك لسيرفرات خارجية وتتوقف عن العمل بانقطاع الإنترنت، تم بناء **MosaSmartNode** ليكون مستقلاً تماماً. بياناتك في بيتك، والتحكم فوري.

> [!WARNING]
> **ملاحظة أمنية وحالة تتبع شهادات الأجهزة (Hardware Certificate State):**
> الجهاز الفيزيائي الحالي في البيئة الاختبارية (`MosaNode_3030F96A1F5C`) يعمل حالياً بـ **شهادة انتقالية مؤقتة** موقعة من CA القديم لغرض الاختبار المخبري والتطوير فقط.
> **لا يُعتمد على هذا الجهاز أو أي شهادة سابقة في أي بيئة إنتاجية نهائية** حتى يتم إتمام دورة حياة الـ PKI الهرمية الجديدة (2-Tier Root & Intermediate CA) ومسار التجهيز الآمن (OTES CSR Flow).

## 🧠 الجزء الأول - العقل (ESP32 Firmware)
تم استخدام شريحة **ESP32-S3** (ثنائية النواة، مدمجة بـ WiFi) كعقل مدبر.

### التطورات التقنية الأساسية (الإصدار 3.0):
1. **Non-blocking ACS712:** تحويل قراءة مستشعر التيار من إيقاف المعالج (Blocking) إلى نظام حالة (State Machine) لضمان استجابة فورية.
2. **Non-blocking DHT22:** قراءة الحرارة والرطوبة دون تجميد النظام المتبقي.
3. **Dirty Flag Broadcasting:** إرسال التحديثات (JSON) للمتصفح فقط عند التغيير وبمعدل محدد (Batching) لتخفيف الضغط على الشبكة.
4. **Flash Write Batching:** تقليل عمليات الكتابة على الذاكرة الداخلية (Flash) لحمايتها من التلف المبكر، بحيث يتم الحفظ كل 10 ثوانٍ كحد أقصى للعمليات المتراكمة.
5. **API Security:** تأمين نقاط الاتصال المحلية بـ API Key لمنع أي تحكم غير مصرح به.

### ميزات متقدمة في الـ Firmware:
- **تحديث هوائي آمن (OTA)** محمي بـ API.
- **RTC DS3231:** وقت دقيق حتى بانقطاع الإنترنت.
- **شاشة OLED:** لعرض الحالة المحلية.
- **AP Fallback:** إنشاء شبكة طوارئ عند فشل الاتصال بالراوتر.
- **Staggered Startup:** تشغيل متدرج للأجهزة عند عودة الكهرباء لمنع سحب تيار عالي مفاجئ.
- **Compressor Protection:** حماية المكيفات من قصر الدورة (تأخير 3 دقائق).

## 💻 الجزء الثاني - الواجهة (Next.js 14)
انتقلت الواجهة من تطبيق React بسيط يعمل على شبكة محلية فقط، إلى منصة حديثة (Monorepo) متكاملة:

### التصميم (UI/UX) والتجربة البصرية:
- **Glassmorphism:** تصميم زجاجي عصري مع إضاءات نيون (Glow) تتفاعل مع نوع الجهاز وحالته.
- **تفاعلات حية:** أيقونات متحركة (مروحة تدور، تأثير التنفس للإضاءة).
- **تصميم متجاوب:** لوحة تحكم شبكية مع دعم السحب والإفلات (Drag & Drop).
- **تجربة سلسة:** اهتزاز لمسي (Haptic Feedback) وإشعارات لحظية.

### البنية البرمجية (Monorepo):
- **Web:** تطبيق Next.js 14 App Router.
- **API:** خادم Node.js / Fastify.
- **Database:** PostgreSQL عبر Drizzle ORM.
- **Infrastructure:** Docker Compose (Postgres, Redis, Mosquitto).

## 🏗️ الجزء الثالث - المعمارية والاتصالات (Hybrid Architecture)

### تحديات تم حلها:
1. **الوصول الخارجي:** يعمل Node.js كـ Local Agent متصل بـ Cloudflare Tunnel لتوفير وصول آمن من أي مكان بالعالم بدون فتح منافذ (Port Forwarding).
2. **بروتوكول MQTT:** تم الانتقال من خوادم عامة إلى خادم Mosquitto محلي محمي بـ TLS وكلمات مرور، لضمان بقاء البيانات داخل الشبكة.
3. **الاكتشاف التلقائي (mDNS):** تقوم واجهة Node.js باكتشاف أجهزة ESP32 في الشبكة تلقائياً وربطها بـ MQTT.

### مسار البيانات:
- **محلياً:** الهاتف ← WiFi ← Node.js API ← MQTT ← ESP32
- **خارجياً:** الهاتف ← Cloudflare Tunnel ← Node.js API ← MQTT ← ESP32

## 🔌 الجزء الرابع - الهاردوير (Custom PCB)

تم تصميم لوحة إلكترونية (PCB) مخصصة لاحتواء النظام بالكامل:
- **المتحكم:** ESP32-S3
- **القيادة:** 2x ULN2803A مع PC817 Optocouplers לעزل المعالج عن الكهرباء العالية.
- **الطاقة:** 10 ريليات 5V للتحكم بجهد 220V.
- **المستشعرات:** ACS712 (تيار)، DHT22 (حرارة/رطوبة)، PIR (حركة).
- **التنظيم الكهربائي:** HLK-PM01 (تحويل 220V إلى 5V) و LD33V (تنظيم 3.3V).

*(ملاحظة: تم تصحيح مسارات الطاقة لتتحمل الحرارة، وتم تأريض المنافذ غير المستخدمة في ULN2803A لمنع الترددات العشوائية).*
