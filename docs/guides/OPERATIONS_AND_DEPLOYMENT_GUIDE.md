# 📘 دليل التشغيل والنشر الشامل لمنصة MOSA Smart Home Platform

مرحباً بك في الدليل النهائي والتشغيلي لمنصة **MOSA Smart Home** الجاهزة بالكامل للإنتاج التجاري (100% Production Ready).

---

## 🚀 1. التشغيل والإدارة عبر Docker Desktop / Raspberry Pi

### تشغيل المنصة بالكامل:
```bash
docker compose up -d --build
```

### التحقق من حالة كافة الخدمات:
```bash
docker ps
```

### إيقاف أو إعادة تشغيل المنصة:
```bash
# إعادة تشغيل المنصة
docker compose restart

# إيقاف الحاويات مع حفظ البيانات
docker compose down
```

---

## 🛡️ 2. التشفير ومنافذ الاتصال (Security Architecture)

- **Port 8883 (mTLS Broker):** منفذ التشفير الرئيسي للـ ESP32 والـ Backend باستخدام TLS v1.3 وشهادات X.509.
- **Port 9001 (WSS mTLS Broker):** منفذ اتصالات الويب المشفر للـ WebSockets.
- **Port 1883:** مغلق نهائياً وغير متاح لحماية البيانات من التنصت.
- **Port 80 / 443 (Nginx Reverse Proxy):** واجهة لوحة التحكم (`http://localhost` أو `https://localhost`).

---

## 📡 3. برمجة وتوصيل لوحات الـ ESP32 الجديدة

1. افتح ملف البرمجة الرئيسي `R1_Refactored/R1_Refactored.ino` في **Arduino IDE**.
2. تأكد من إدخال الـ IP الخاص بالخادم في السطر 46:
   ```cpp
   const char* default_mqtt_host = "192.168.1.102"; // IP حاسوبك / الخادم
   ```
3. اختر اللوحة `ESP32-S3 Dev Module` واضغط **Upload**.
4. بمجرد الاتصال، ستظهر اللوحة فوراً في لوحة التحكم وتتصل عبر Port 8883 المشفر.
