# SRE Runbook: Data Restoration

## الغرض (Purpose)
يشرح هذا الدليل كيفية استعادة قاعدة بيانات PostgreSQL ومعلومات جلسات Redis في حال فساد البيانات أو الكوارث.

## متطلبات مسبقة
- يجب أن تمتلك ملف الـ `db.dump` من مسار `backups/`.
- توقف النظام جزئياً للسماح بالاستعادة (صيانة مجدولة).

## الإجراءات (Procedure)

### استعادة قاعدة البيانات
1. حدد آخر نسخة احتياطية صالحة عبر الأمر: `ls -la backups/`
2. قم بإيقاف الحاويات المرتبطة بالقاعدة لتجنب التضارب (الـ Backend):
   `docker stop mosa-backend`
3. قم بتشغيل سكربت الاستعادة المخصص:
   `./scripts/restore.sh ./backups/2026xxxx_xxxxxx/db.dump`
4. تأكد من ظهور رسالة النجاح (✅).
5. أعد تشغيل الباك إند: `docker start mosa-backend`
6. قم بإجراء اختبار سريع (Smoke Test) بفتح لوحة القيادة.
